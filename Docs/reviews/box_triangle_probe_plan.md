**M2 — interior straddle chart (pole at 0.9617) crossed with the real-log split while carrying log towers.** The straddle guard (:507-521) warns only when the *extracted* b≠0; DecomposeSingularity silently clamps non-rationalizable/complex collapsed b to 0 (SingularityDecomposition.m:351-362), so a multi-sector straddle enters the `$InteriorSplitRealLog` split (:522-530) without warning. **M3 — per-run transport continuation failure.** Run3 (not run2) shows "multivalued … not recognized as a branch point" during the L3 work: Transport.m:480-492 → GiveMultivaluedError (:470-478), neutered by `"AbortOnAnalyticContinuationFail"->False` (DiffExpIntegration.m:411-414, 466-469); `PrescribeMatrixFactors->False` means true matrix-alphabet factors (beyond {xx3, 1−xx3, IBP pole}) get no iδ prescription.
